# Humand Shifts · Prototipo de programación automática de turnos

Prototipo navegable de la Parte 2 del caso de PM de Humand (Shift Management), con la empresa ficticia Luna Zapatería.

- `index.html`: app web, Turnos laborales (grilla semanal, cobertura por vistas de estacionalidad, conflictos, botón Programar).
- `admin.html`: Admin, Horarios laborales (lista, calendario y reglas).
- `motor.js`: motor de reglas de la programación automática (restricciones y criterios con peso).
- `datos.js`: datos de ejemplo compartidos (colaboradores, turnos, licencias, historial, vistas de cobertura).
- `iconos.js`: íconos SVG compartidos.

Sitio estático, sin build. Cada push a `main` se publica en Vercel.
